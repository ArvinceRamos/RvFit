## Next: Phase 4, lighter and faster

From the audit (session "RvFit comprehensive product audit"). The roadmap says:
- **H9, static ribbon on app pages.** The 3D ribbon redraws nonstop behind every app page, under frosted-glass cards that are re-blurred each frame, with no frame-rate cap in full mode (`src/app/layout.tsx`). Fix: on app pages draw one frame and redraw only on scroll or page change; keep 3D motion on landing and auth pages. Possible WCAG 2.2.2 issue (motion with no pause).
- **H10, server-rendered daily pages.** Dashboard, Week, Progress and Meals load data through Server Actions called from `useEffect` (`dashboard-view.tsx`, `week-view.tsx`, `progress-view.tsx`, `meal-days-view.tsx`). That is a waterfall: shell, hydrate, POST, render. Next docs say actions are for mutations and run one at a time. Fix: save the user's time zone in a cookie, render these pages on the server, and pin the Vercel region next to Supabase (Tokyo). This also fixes dates formatted with the server's clock.
- **Proxy, bundle and refresh fixes:**
  - F8: the proxy matcher covers prerendered pages, `/api/health`, prefetches and every action POST, and each does an Auth `/user` call. Use `getClaims()` in the proxy and `requireUser` (keep `getUser` for account deletion and password changes); narrow the matcher to app routes plus /login and /signup.
  - F9: supabase-js (51 KB gz) is in every page's initial JS through error/not-found → AuthFrame → SignedInNav → LogoutButton. Make logout a server action or load the client lazily; give error and not-found pages a frame without the nav.
  - F11: every write does the action, then a client `router.refresh()` (12 call sites). Call `refresh()` from `next/cache` inside the mutating actions and drop the `router.refresh()` calls. Read `node_modules/next/dist/docs/` first (server-actions.md).
- **5-item navigation** (audit section 3): Today (Dashboard), Food (Today / Plan / History tabs; Browse foods as a search inside; Food settings for allergies and avoided foods), Train (plan with Next up, Log, Recent; Change plan for experience, equipment, days), Progress (weigh-in first, trend, chart, 7-day kcal strip, check-in), Me (Profile). A bottom tab bar on phones. Week merges into Today and Progress. URLs can stay; this changes `src/lib/nav.ts` and page sections, not features.

A sensible order: AU-61 H9 (small), AU-62 proxy, bundle and refresh fixes, AU-63 H10 (largest), AU-64 the 5-item navigation. Send the 3–5 line plan and ask "Want me to start Job N?" (CLAUDE.md), unless the user delegates Phase 4 the way they delegated Phase 3.
